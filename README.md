# Cheese Store Mini App

Мобильная демонстрационная витрина цифровых товаров в чёрно-жёлтом стиле. Бот: [@testerminiapp_bot](https://t.me/testerminiapp_bot).

## Возможности

- Каталог категорий и семь вариантов Telegram Premium.
- Калькулятор Telegram Stars по демонстрационному курсу 1,5 ₽.
- Выбор получателя, подтверждение и история демозаказов.
- Профиль и пополнение виртуального баланса.
- Поддержка Telegram WebApp SDK и гостевого режима в браузере.

Реальных платежей, выдачи товаров и обращений к Bot API нет. Баланс и заказы хранятся только в памяти страницы и сбрасываются при перезагрузке. Другие категории показывают экран «скоро». Цены взяты из предоставленного каталога и не обновляются автоматически.

## Запуск

Откройте `index.html` в браузере или разместите файлы на статическом HTTPS-хостинге. Сборка и установка зависимостей не требуются. Внешние ресурсы: Telegram WebApp SDK и шрифт Manrope из Google Fonts.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и сохраните. Файл `.nojekyll` отключает обработку Jekyll.

После успешной публикации используйте URL, показанный в Pages. В @BotFather отправьте `/setmenubutton`, выберите `@testerminiapp_bot`, укажите опубликованный HTTPS-адрес и текст кнопки `🧀 Магазин`.

Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Файлы

- `index.html` — оболочка приложения.
- `style.css` — дизайн Cheese Store.
- `app.js` — навигация, калькулятор и демонстрационные операции.

Токен бота для этого статического демо не требуется. Секреты в исходниках отсутствуют.
